# Catalog sources

Verified 25 November 2026. Only available adapters appear in Catalog Import. Images are copied locally after byte, dimension, host and duplicate checks. Prices, stock and promotions are explicit ShopNest settings; source adapters do not invent them or infer saleable variants.

| Source | Supported content | Remaining requirements |
| --- | --- | --- |
| Open Food Facts / Open Beauty Facts | Actual taxonomy, supplied names, brands, identifiers, specifications and distinct full-resolution images; original attribution and licences retained. Completeness varies. | No credentials needed. Strict image filters can exhaust sparse categories; the preview reports the actual result. |
| Amazon Berkeley Objects (ABO) | Historical general merchandise: furniture, home, footwear, accessories, electronics and some appliances/clothing. Actual multilingual listing data, supplied specifications and original catalog photos. No live price, inventory or verified variant-family links. | No credentials needed. The publisher currently licenses assets under CC BY 4.0; attribution is stored and displayed. Initial metadata preparation downloads roughly 12 MB; cached metadata is reused, and additional listing shards load as needed. Category discovery currently reflects 296 real product types found in the first listing shard, rather than a complete Amazon marketplace taxonomy. |
| Historical Amazon Reviews 2023 adapter | Incremental metadata-file discovery and bounded range reads, supplied brand/specifications and images. No customer/review data is imported. | Obtain content-owner permission covering the intended copying, storage and public redistribution of descriptions/images, including commercial use where applicable. Then set `AMAZON_CATALOG_LICENSE_CONFIRMED=true`. `AMAZON_CATALOG_URL` must expose the expected metadata files and support byte ranges. The public default does not require an invented API key; host authentication is needed only if the selected dataset requires it. The dataset publisher explicitly says it cannot assign a reuse licence. |
| Daraz | Implemented seller-authorized product/category retrieval, local descendant-category filtering and SKU image collection. Signed requests and normalization have automated tests; no live seller account was available. | Approved Pakistan Open Platform application with product/category read access; `DARAZ_APP_KEY`, `DARAZ_APP_SECRET`, `DARAZ_ACCESS_TOKEN` for an authorized seller; seller/content-owner permission to reuse content outside Daraz. A valid access token must be supplied and renewed externally; OAuth consent and automatic token refresh are not implemented. This is the authorized seller's assortment, not unrestricted marketplace-wide discovery. |
| Open Icecat | No adapter or selectable option is claimed. | Channel Partner account and confirmed Open/Full catalog and asset entitlements; API token required for Full and recommended for Open (Open requests can use `shopname` without a token), with a content token recommended for entitled asset downloads; an accessible product index/PIF or supplier GTIN/brand+MPN/ID list for discovery; permission for required high-resolution assets and local copying. An adapter, representative-account sample and live acceptance tests are still required. Bulk requests should use Icecat's documented origin endpoint rather than the interactive CDN. |

Primary references: [ABO publisher and current licence](https://amazon-berkeley-objects.s3.amazonaws.com/index.html), [historical Amazon publisher clarification](https://huggingface.co/datasets/McAuley-Lab/Amazon-Reviews-2023/discussions/1), [Daraz Open Platform](https://open.daraz.com/doc/doc.htm), [Icecat JSON manual](https://iceclog.com/manual-for-icecat-json-product-requests/), [Icecat batch discovery](https://iceclog.com/manual-icecat-product-xmls-batch-processing/).

ABO was selected because it supplies reusable real product content and multiple original photos. Research-only fashion datasets such as [DeepFashion](https://mmlab.ie.cuhk.edu.hk/projects/DeepFashion.html) do not supply a general commercial redistribution licence and are not integrated. Broader current fashion, furniture and appliance coverage still needs authorized manufacturer/supplier feeds or licensed Icecat access; no universal public feed is claimed. DummyJSON remains test-only.
